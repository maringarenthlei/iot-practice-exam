Practical lab checklist

IoT essentials

Sense → process → connect → analyse → act. An IoT solution links sensors and actuators through a device, network and application or cloud layer.

Hardware quick sheet

Arduino is a microcontroller board for direct hardware control. Raspberry Pi is a single-board computer that can run an operating system. ESP32 and NodeMCU are popular connected IoT boards.

Networking quick sheet

Choose technology by range, power and data needs. Wi-Fi suits local higher-data connectivity; BLE is short range and low power; LoRaWAN and NB-IoT support low-power wide-area use cases.

MQTT, cloud and data

MQTT uses a broker and a publish-subscribe model. Cloud platforms can collect, store, visualise and manage device data. Use timestamps, thresholds and alerts meaningfully.

Security quick sheet

Use unique credentials, change defaults, patch firmware, encrypt data in transit and grant only necessary access. Design privacy into data collection.

Mini-project ideas

Smart irrigation

Use soil-moisture data to control a pump or relay. Add a manual override and record water events.

Water-tank monitor

Measure level with an ultrasonic sensor, show a percentage and trigger an alert at high or low thresholds.

Air-quality monitor

Read a gas sensor, display a trend and send threshold alerts to an IoT dashboard.

Smart room monitor

Combine temperature, light and motion data to create a simple monitoring dashboard.
