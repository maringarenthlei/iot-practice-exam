# Fundamentals of IoT Practice Examination

A buildless, static practice-exam website for the NIELIT Fundamentals of Internet of Things curriculum (NSQF Level 4). The 200-question learning bank supplies a newly randomised 100-question practice attempt each time.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `iot-practice-exam`.
2. Upload every file in this folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show your public website URL after the build completes.

## Notes

- The website has no backend and does not send or store personal data.
- Question content is for self-practice only. It is not an official NIELIT question paper or assessment platform.
